# Road_Crack_Software
The Road Crack Detection System is a Python and OpenCV tool that analyzes pictures of roads and automatically grades the damage or crack as Low, Medium, or High based on the size of the cracks. It can check a single photo or quickly scan through large Kaggle datasets by O(n) time complexity, saving the results using Hash Maps. The system currently works by finding dark shadows on the road surface, but I am actively updating it to handle tricky real-world situations—like water-filled potholes that reflect the sky—by adding edge detection so the system doesn't get confused by the water.
